SAFE INSTALLATION
1) Make a backup of D:\AgroRoute_AI (or make sure Git has your latest commit).
2) Extract the ZIP. Open the AgroRoute_AI folder inside.
3) Copy its CONTENTS into D:\AgroRoute_AI, replacing code files.
4) KEEP your existing .git, .venv, data/plant_leaves, models/mobile_net_v2
   and any .streamlit/secrets.toml. They are intentionally not in this ZIP.
5) If Streamlit is running, Ctrl+C, then restart in PowerShell:
      cd D:\AgroRoute_AI
      .\.venv\Scripts\python.exe -m pip install -r requirements.txt
      .\.venv\Scripts\python.exe -m unittest discover -s tests -v
      .\.venv\Scripts\python.exe -m streamlit run app.py
6) Verify page rendering and chart alignment on your browser. A full
   Streamlit browser smoke test was not run in the packaging environment.

SAFETY NOTES
