\# Contributing to AgroRoute AI



Thank you for contributing to AgroRoute AI.



\## Development Branches



Development work should be performed on a feature branch rather than directly on `main`.



Recommended branch naming:



\- `Ainesh-\*` for Ainesh development work

\- `feature-\*` for general feature work

\- `fix-\*` for bug fixes

\- `docs-\*` for documentation changes
